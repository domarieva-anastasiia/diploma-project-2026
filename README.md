# SRGAN Backend Server & Model Architecture (diploma project 2026)

Цей репозиторій містить серверну частину дипломного проєкту, включаючи архітектурні компоненти нейромережі SRGAN, функції обробки даних та інфраструктуру для локального й хмарного розгортання.

## Нейронні мережі

* **Модулі нейромережі:** Реалізація генератора SRResNet та трьох конфігурацій дискримінаторів - BASE, GAP, PatchGAN.
* **Train-step функція:** Опис кроку навчання з комбінованою функцією втрат для генератора.
* **Функції втрат:** Реалізація змагальної втрати, втрати контенту на основі функцій VGG та попіксельної втрати.
* **Нормалізація та метрики:** Функції преведення колірного діапазону до значень [0, 1] та [0, 255] та оцінки якості зображень - метрики PSNR та SSIM.

## Серверна частина

* **Серверний API Flask:** Веб-сервер, який приймає вхідні HTTP-запити із зображеннями низької роздільної здатності від клієнтської частини (мобільного застосунку), координує роботу системи та повертає оброблені результати.
* **Асинхронна черга завдань Celery:** Система фонової обробки тривалих обчислень. Дозволяє усунути блокування HTTP-сервера під час роботи нейромережі, делегуючи задачі воркерам та підтримуючи динамічне оновлення статусів прогресу для користувача.
